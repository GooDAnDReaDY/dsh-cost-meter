# dsh-cost-meter

Чип стоимости сессии в шапке диалога DeepSeek Harness: живой расход по токенам,
текущий тариф (пик / не-пик) и обратный отсчёт до его смены.

```
● ≈ ₽8.55  0:17     ← чип в conversation.session.header.utilities
```

По клику раскрывается панель: тарифная таблица за 1M токенов в двух колонках
(не-пик / пик, активная выделена), окна пика в UTC и итог за сессию.

## Откуда берутся цифры

**Токены** — из проекции `tokenUsage`, которую публикует штатный
`@deepseek-ai/dsh-token-meter`: четыре непересекающиеся корзины
(`cacheReadTokens`, `uncachedInputTokens`, `cacheWriteTokens`, `outputTokens`).
Сессионный слот отдаёт компоненту `useProjection`, поэтому значения обновляются
прямо во время стрима, без опроса.

**Цены** — из конфига этого плагина. Харнесс намеренно не считает деньги: у
pi-ai есть поле `cost`, но оно занулено, и в коде прямо сказано, что ни один
потребитель не отчитывается о тратах. Поэтому тарифная карта живёт здесь и
правится в GUI (Настройки → dsh-cost-meter) или в патч-слое профиля.

**Тариф** считается по часам UTC на клиенте: окна пика из конфига, вне их —
множитель `offPeakMultiplier`.

## Установка

```bash
dsh plugin --profile web add file:/path/to/dsh-cost-meter
sudo systemctl restart dsh-web        # или перезапустите dsh web вручную
```

Локальные плагины подключайте через `file:`, а не `link:` — при `link:` Node
резолвит импорты от реального пути вне профиля и не находит peer-зависимости.

## Конфигурация

| Поле | По умолчанию | Значение |
|---|---|---|
| `currency` | `$` | символ валюты в чипе |
| `usdRate` | `1` | сколько единиц валюты в одном USD; `1` — считать в долларах |
| `peakWindowsUtc` | `[]` | окна пика `HH:MM-HH:MM` в UTC; окно может пересекать полночь |
| `offPeakMultiplier` | `1` | множитель ко всем ставкам вне пика |
| `prices` | `{}` | тарифная карта по ключу `провайдер/модель`; ключ `*` — запасной |

Ставки задаются **пиковые**, в USD за 1M токенов; не-пик получается умножением
на `offPeakMultiplier`. Пример для профиля:

```yaml
- id: dsh-cost-meter
  config:
    currency: '₽'
    usdRate: 80
    peakWindowsUtc: ['01:00-04:00', '06:00-10:00']
    offPeakMultiplier: 0.5
    prices:
      '*':
        cacheHit: 0.014
        input: 0.44
        cacheWrite: 0.44
        output: 1.32
```

## Ограничения

- Считается **дефолтный маршрут** агента (`agent-default-model`), а не модель
  каждого отдельного запроса. Если в одной сессии менялись модели, итог будет
  посчитан по текущей ставке — отсюда `≈` перед суммой.
- Данные приходят из usage, который присылает провайдер. Маршруты, не
  сообщающие usage, дадут нули: в панели об этом сказано явно.
- Курс валюты — константа `usdRate`, живого курса плагин не тянет.

## Устройство

| Файл | Что делает |
|---|---|
| `lib/index.js` | конфиг, namespace настроек, маршрут `GET /dsh-cost-meter/state` |
| `lib/client.js` | чип и панель; читает `tokenUsage`, считает арифметику |
| `cordis.patch.yml` | строка плагина в дереве загрузчика профиля |

Хост не вешает ни одного хука на ход агента — виджет только читает. Плагин,
который ничего не инжектит в сессию, не может её испортить.
