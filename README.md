# dsh-cost-meter

Чип стоимости сессии в шапке диалога DeepSeek Harness: живой расход по токенам,
текущий тариф (пик / не-пик) и обратный отсчёт до его смены.

```
● ≈ ₽8.55  0:17     ← чип в conversation.session.header.utilities
```

По клику раскрывается панель: тарифная таблица за 1M токенов в двух колонках
(не-пик / пик, активная выделена), окна пика в UTC и итог за сессию.

## Откуда берутся цифры

**Токены** — из собственной проекции сессии `costByModel`, которую плагин
регистрирует тем же механизмом, что и штатный `@deepseek-ai/dsh-token-meter`.
В журнале есть всё нужное: `request/header` несёт `config: {provider, model}`,
а usage приходит следом за тем же шагом, поэтому каждая выборка относится к
модели, которая её заработала.

Накопление идёт не одной кучей, а по **получасовым слотам суток UTC**: расход
фиксируется по ставке, действовавшей в момент трат, и переключение тарифа не
пересчитывает уже потраченное. Все реальные окна выровнены по получасу, так что
слот воспроизводит ставку точно.

Сессионный слот отдаёт компоненту `useProjection`, поэтому значения обновляются
прямо во время стрима, без опроса.

**Цены** берутся из трёх источников, в таком порядке:

1. **Ручные `prices`** из конфига — для подписок и локальных моделей.
2. **Официальный прайс DeepSeek** — по имени модели, а не по провайдеру:
   `deepseek-v4-flash` стоит столько, сколько объявил DeepSeek, кто бы её ни
   маршрутизировал, а суффиксы версий (`deepseek-v4-flash:0731`) сводятся к той
   же модели. Таблица зашита в плагин: у DeepSeek нет эндпоинта с
   ценами (`/models` отдаёт только id, `/pricing` — 404), а записи `deepseek/*`
   в OpenRouter — это чужой хостинг с другими ставками. Тариф двухуровневый:
   пик 01:00–04:00 и 06:00–10:00 UTC, вне окон — ровно половина.
3. **Каталог OpenRouter** (`https://openrouter.ai/api/v1/models`, без ключа) —
   для всех остальных. Оттуда четыре ставки (`prompt`, `completion`,
   `input_cache_read`, `input_cache_write`) и, если есть, `pricing.overrides` —
   окна скидок по времени суток. Каталог кэшируется на диск и обновляется раз в
   сутки; без сети работает последний кэш.

Если модель не нашлась нигде, виджет пишет «тариф ?» и объясняет, что делать,
вместо того чтобы показать правдоподобный ноль.

Сам харнесс цен не знает и знать не хочет: у pi-ai есть поле `cost`, но оно
занулено, и в коде прямо сказано, что ни один потребитель не отчитывается о
тратах. Поэтому источник — внешний.

**Тариф** вычисляется на клиенте по часам UTC: активная ставка = подходящее
окно, иначе базовая. Если окон два — таблица показывает обе колонки, активная
подсвечена, рядом обратный отсчёт до смены. Часы выводятся в зоне
`displayTimeZone` (по умолчанию московской) через `Intl`, так что переход на
летнее время учитывается. Если окон нет — одна колонка «ставка» без подсветки.

## Установка из приватного registry

```bash
dsh plugin --profile web add @goodandready-private/dsh-cost-meter
sudo systemctl restart dsh-web
```

Пакет публикуется в приватный GitHub Packages registry. Исходная разработка,
изолированная проверка и production-установка выполняются через Git и пакетный
маршрут; локальные установки из исходного checkout не являются поддерживаемым
способом развёртывания.

## Конфигурация

| Поле | По умолчанию | Значение |
|---|---|---|
| `currency` | `$` | символ валюты в чипе |
| `usdRate` | `1` | сколько единиц валюты в одном USD; `1` — считать в долларах |
| `useOpenRouter` | `true` | тянуть ставки и окна скидок из каталога |
| `displayTimeZone` | `Europe/Moscow` | в какой зоне показывать часы тарифа |
| `deepseekPeakPrices` | `{}` | переопределить встроенные пиковые ставки DeepSeek |
| `refreshHours` | `24` | как часто обновлять каталог |
| `modelMap` | `{}` | сопоставление `провайдер/модель` → id модели в OpenRouter |
| `prices` | `{}` | ручные ставки по ключу `провайдер/модель` (или `*`); **перекрывают каталог** |
| `manualPeakWindowsUtc` | `[]` | окна пика `HH:MM-HH:MM` UTC — только для ручных ставок |
| `manualOffPeakMultiplier` | `1` | множитель вне окон — только для ручных ставок |

Обычно хватает валюты и курса:

```yaml
- id: dsh-cost-meter
  config:
    currency: '₽'
    usdRate: 80
```

Модель сопоставляется с каталогом по точному id, затем по суффиксу:
`deepseek-official/deepseek-v4-flash` → `deepseek/deepseek-v4-flash`. Если
угадано неверно или модели в каталоге нет — либо `modelMap`, либо ручные ставки:

```yaml
    modelMap:
      'ollama/glm-5.2': 'z-ai/glm-5.2'
    prices:
      'opencode-go/minimax-m3':      # подписка — считать бесплатным
        cacheHit: 0
        input: 0
        cacheWrite: 0
        output: 0
```

## Ограничения

- Модель DeepSeek, вызванная **через OpenRouter**, всё равно считается по
  официальному прайсу DeepSeek, хотя счёт выставит OpenRouter. Помечено в коде.
- Данные приходят из usage, который присылает провайдер. Маршруты, не
  сообщающие usage, дадут нули: в панели об этом сказано явно.
- Модели, для которых тариф не нашёлся, показываются отдельной строкой и в
  сумму не входят — сумма честно неполная, а не занижена молча.
- Курс валюты — константа `usdRate`, живого курса плагин не тянет.

## Устройство

| Файл | Что делает |
|---|---|
| `lib/index.js` | конфиг, проекция `costByModel`, тарифы, маршрут `GET /dsh-cost-meter/state` |
| `lib/client.js` | чип и панель; читает проекцию, считает арифметику по слотам |
| `cordis.patch.yml` | строка плагина в дереве загрузчика профиля |

Хост не вешает ни одного хука на ход агента — виджет только читает. Плагин,
который ничего не инжектит в сессию, не может её испортить.
