# DESIGN.md — dsh-cost-meter

## Product / Purpose
- Назначение: Отображение стоимости активной сессии диалога в реальном времени, тарифов (пик / не-пик / единый) за 1M токенов, обратного отсчёта до смены окна и прозрачной детализации расходов по каждой задействованной модели.
- Аудитория: Пользователи и инженеры DeepSeek Harness, контролирующие потребление токенов и бюджет на LLM-провайдеров.
- Статус: Активная публичная поставка (@goodandready/dsh-cost-meter).

## User Surfaces
- Web/UI:
  - Компактный чип в слоте `conversation.session.header.utilities` (order: 10).
  - Выпадающая панель детализации (width: 320px, absolute positioning, click-outside dismissal).
- DSH UI / settings / slots:
  - Слот: `conversation.session.header.utilities`.
  - Настройки: реестр DSH `settings.register("dsh-cost-meter", Config)` (валюта `currency`, множитель курса `usdRate`, таймзона `displayTimeZone`, опрос OpenRouter `useOpenRouter`, ручные ставки `prices`, сопоставление `modelMap`).
- API:
  - HTTP `GET /dsh-cost-meter/state` (параметр `?models=...` для получения тарифов по задействованным моделям).
- CLI:
  - Управление через CLI харнесса: `dsh plugin --profile web add @goodandready/dsh-cost-meter`.
- Документация:
  - README.md, index.md, docs/testing/public-route.md, docs/deployment/public-release.md.

## Visual Direction
- Атмосфера: Строгий утилитарный нативный интерфейс DSH, высокая информационная плотность без визуального шума.
- Утверждённые референсы: Дизайн-система DeepSeek Harness (`--dsw-alias-*`), чипы в шапке сессии (`dsh-key-rotation`, `dsh-context-lens`).
- Не копировать: Избыточные градиенты, внешние модальные окна, тяжелые тени, кастомные несогласованные шрифты.

## Foundations
- Цвета и роли:
  - `--dsw-alias-label-primary`: основной текст, заголовки, суммы.
  - `--dsw-alias-label-tertiary`: второстепенные пояснения, метки столбцов, чип без тарифа.
  - `--dsw-alias-border-l2`: разделители секций и обводка панели.
  - `--dsw-alias-bg-layer-2` / `--dsw-alias-bg-base`: подложка всплывающей панели.
  - `--dsw-alias-state-success-primary` / `--dsw-alias-state-success-tertiary`: подсветка льготного окна (не-пик).
  - `--dsw-alias-state-warn-primary` / `--dsw-alias-state-warn-tertiary`: подсветка полного тарифа (пик).
- Типографика:
  - Системный стек шрифтов DSH, размер 12px, интерлиньяж 1.5.
  - Обязательно `fontVariantNumeric: "tabular-nums"` для всех числовых колонок, токенов и таймеров.
- Сетка и отступы:
  - Чип: высота 22px, padding: 0 8px, gap: 6px, border-radius: 6px.
  - Панель: padding: 12px 14px, border-radius: 10px, ширина 320px.
  - Сетки: `grid` с выравниванием числовых колонок по правому краю (`text-align: right`).
- Accessibility:
  - Семантические теги `button` для интерактивных элементов, нативные `title` подсказки при наведении, закрытие панели при клике вне компонента.

## Components And States
- Чип:
  - `Loading / Init`: если данные ещё не загружены, чип скрыт (`null`).
  - `Unknown Tariff`: отображает «тариф ?» в приглушённом цвете `label-tertiary`.
  - `Flat Tariff`: фон `--dsw-alias-state-warn-tertiary`, текст `--dsw-alias-state-warn-primary`, заголовок «Единый тариф».
  - `Off-Peak`: зелёная плашка успеха (льготный тариф).
  - `Peak`: оранжевая плашка предупреждения (полный тариф).
  - Таймер: время до смены тарифа с пониженной непрозрачностью (`opacity: 0.75`).
- Панель:
  - Заголовок с текущей моделью и статусом окна.
  - Сетка тарифов за 1M токенов (не-пик / пик / единая ставка).
  - Блок «Из чего сложилась сумма»:
    - Список всех моделей сессии с токенами и суммарной стоимостью.
    - Для модели без тарифа отображается статус `не указана стоимость`.
  - Итог сессии: `Сессия: ≈ <валюта><сумма>`.
  - Отсутствие мусорных служебных плашек (строка источника OpenRouter исключена).

## User Flows
1. Пользователь ведёт диалог с ассистентом: чип в шапке инкрементально обновляет потраченную сумму прямо во время стриминга ответа ассистента.
2. Пользователь нажимает на чип: открывается всплывающая панель с тарифной сеткой и расходами по каждой модели сессии.
3. Если модель не тарифицирована: в списке моделей выводится статус `не указана стоимость`.

## Do / Don't
- Do:
  - Использовать CSS-переменные DSH для согласованности с тёмной и светлой темами.
  - Всегда разделять расходы по задействованным моделям.
  - Использовать табличные цифры (`tabular-nums`) для предотвращения дёргания вёрстки при стриме.
- Don't:
  - Не выводить техническую служебную информацию о каталоге OpenRouter в интерфейс пользователя.
  - Не заменять отсутствие тарифа обманчивым нулём или невнятным прочерком — писать прямо `не указана стоимость`.
  - Не допускать утечек локальных путей и инфраструктурных данных в коде или документации.
