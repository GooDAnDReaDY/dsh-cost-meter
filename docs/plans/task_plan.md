# Task Plan: Issue #25 (v0.8.1) — Оптимизация производительности, ручная синхронизация каталога и подсказки экономии

## Цели
1. **Скорость**:
   - Оптимизация алгоритма расчета времени смены тарифа (`minutesUntilChange`) и экстремумов (`extremes`) с $O(1440)$ до $O(K)$ без полного минутного цикла.
   - Серверный кэш `resolveTariffCache` для быстрого разрешения моделей.
   - Поддержка ETag / 304 Not Modified на эндпоинте `/dsh-cost-meter/state`.
2. **Качество и управление**:
   - Маршрут `POST /dsh-cost-meter/refresh` с rate limit (cooldown 30 сек) и кнопка «Синхронизировать сейчас» в настройках.
   - Таблица нормализации алиасов вендоров (Smart Vendor Aliases).
   - Индикация stale-кэша каталога в UI.
3. **Экономия**:
   - Подсказка в поповере о приближении льготного тарифа (50% скидка).
   - Конфигурируемый порог сессии `budgetThreshold` с предупреждающей подсветкой чипа.
   - Кнопка «Скопировать сводку» в поповере.
4. **Стандарты и релиз**:
   - 100% прохождение тестов `npm test`.
   - Проверка размера файлов (< 256 KiB).
   - Тестирование на test server (MiniPC :3082), затем на MiniAI candidate (:3080).
   - Запрос подтверждения пользователя -> публикация v0.8.1 в npm/GitHub -> rollout на прод.
